# Route 06 Pass 1B.0 — Read-only Output Migration Intelligence

> Executed: 2026-07-30  
> Result: Implemented and verified  
> Route maturity: remains L1 Defined

## Scope

Pass 1B.0 implements only the Output migration inventory and audit accepted by
the Route 06 compatibility contract. It does not migrate Outputs or introduce
canonical Publication production behavior.

## Implemented boundary

- Root command:
  `pnpm run audit:output-migration -- --vault <vault-or-sqlite> --json <report>`
- Selected SQLite databases open with `readOnly: true` and `query_only = ON`.
- Schema version and the `story_outputs` table are validated before reading.
- Reports use contract version `1.0.0`, stable Output/finding ordering, stable
  fingerprints, accepted issue codes, severity counts, and exit codes.
- Output content is never included. Secret-bearing destinations, URL credentials,
  sensitive query parameters, and absolute paths are redacted.
- Similar records remain separate and ambiguous grouping requires user action.
- Exact versioned destination mappings may propose provisional Channel
  definitions; they never create Channels or Connections.
- The report is the only written artifact and is written to the caller-selected
  path outside the audited database.

## Acceptance evidence

`scripts/src/output-migration-audit.test.ts` verifies:

- empty Vault and repeat-run equality;
- database byte fingerprint unchanged after auditing;
- assigned/unassigned Workspace inventory;
- missing Story and cross-Workspace ownership;
- unknown status and invalid format;
- missing title/content;
- duplicate-looking records remain separate and ambiguous grouping is reported;
- deterministic and ambiguous destinations;
- content, URL secrets, secret-like text, and absolute-path redaction;
- schema rejection;
- clean exit code `0` and action-required exit code `2`.

Execution-failure paths map to exit code `1` in the CLI boundary.
